# Scatterplot Graph — Doping in Professional Bicycle Racing

freeCodeCamp Data Visualization certification project.

## What it shows

The 35 fastest times up Alpe d'Huez, from the official freeCodeCamp
dataset:
`https://raw.githubusercontent.com/freeCodeCamp/ProjectReferenceData/master/cyclist-data.json`

Orange dots mark riders with doping allegations; blue dots mark riders
without.

## How to run

Open `index.html` in a browser (serve the folder with any static server,
e.g. `python3 -m http.server`), or host it live. D3.js is loaded from a CDN.

## Tests

The freeCodeCamp test bundle (`bundle.js`, included at the end of
`<body>`) runs the Scatterplot Graph test suite against this page.
